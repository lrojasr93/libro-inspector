# Libro del Inspector

App web para estudiar el trabajo de inspector/a educacional en Chile: fichas, preguntas, casos prácticos y desafío diario. Inicio de sesión con correo y contraseña (Firebase Auth) y avance guardado en Firestore.

- `index.html`: la app completa.
- `firestore.rules`: reglas de Firestore (cada persona solo lee y escribe su propio avance).

El contenido cita fuentes oficiales chilenas (BCN Ley Chile, Mineduc, Superintendencia de Educación). Revisar ante cambios normativos.
